# ⚙️ ASMLings — гайд на русском

📢 **t.me/rust_code** — основной Telegram-канал с уроками и разбором кода для Rust-разработчиков.

Подробное руководство на русском по [asmlings](https://github.com/giacomo-folli/asmlings) — интерактивной песочнице для изучения ассемблера Intel 8086 с мгновенной проверкой решений, написанной на Rust.

> ASMLings — это «rustlings, но для ассемблера 8086». Ты пишешь код в файле, сохраняешь — встроенный 16-битный x86-эмулятор на Rust моментально проверяет, что регистры, флаги и память пришли в нужное состояние.

>           > ## 1. Установка
>           >
>           > ### 1.1 Требования
>           >
>           > - **Rust** (свежий stable). Если ещё нет:
>           > -   ```bash
>           >       curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
>           >       ```
>           >     - **NASM** — ассемблер, на котором собираются твои файлы перед эмуляцией.
>           >  
>           >     - ### 1.2 Установка NASM по ОС
>           >  
>           >     - ```bash
>           >       # macOS
>           >       brew install nasm
>           >
>           >       # Ubuntu / Debian
>           >       sudo apt install nasm
>           >
>           >       # Arch Linux
>           >       sudo pacman -S nasm
>           >
>           >       # Windows
>           >       winget install NASM
>           >       ```
>           >
>           > ### 1.3 Установка asmlings
>           >
>           > Самый быстрый способ — через `cargo-binstall` (без долгой компиляции):
>           >
>           > ```bash
>           > cargo install cargo-binstall
>           > cargo binstall asmlings
>           > ```
>           >
>           > Через обычный cargo (с компиляцией):
>           >
>           > ```bash
>           > cargo install asmlings
>           > ```
>           >
>           > Можно также скачать готовый бинарник со страницы [Releases](https://github.com/giacomo-folli/asmlings/releases).
>           >
>           > ### 1.4 Troubleshooting (Linux)
>           >
>           > Если `cargo install asmlings` падает с ошибкой линковщика про `__atomic_compare_exchange_16` или `undefined symbol`, нужно подключить `libatomic`:
>           >
>           > ```bash
>           > RUSTFLAGS="-Clink-arg=-latomic" cargo install asmlings
>           > ```
>           >
>           > Если линкер ругается, что `-latomic` не найден — поставь библиотеку:
>           >
>           > ```bash
>           > # Ubuntu / Debian
>           > sudo apt install libatomic1
>           >
>           > # Arch
>           > sudo pacman -S gcc-libs
>           >
>           > # Fedora / RHEL
>           > sudo dnf install libatomic
>           > ```

>           >
>           > ## 3. Как устроено упражнение
>           >
>           > Каждый файл в `exercises/` — это самодостаточный `.asm`-файл с инструкциями 8086 и комментариями-директивами. Чтобы пройти упражнение, нужно сделать **две вещи**:
>           >
>           > 1. **Удовлетворить ассерты.** В файле есть строки вида:
>           > 2.    ```asm
>           >          ; ASSERT_REG: AX == 0x1337
>           >          ; ASSERT_MEM: [0x0200] == 0x42
>           >          ; ASSERT_FLAG: ZF == 1
>           >          ```
>           >          После выполнения твоего кода регистры, память и флаги должны быть точно в указанном состоянии.
>           >
>           > 2. **Убрать «сентинель».** В каждом файле есть строка:
>           > 3.    ```asm
>           >          ; I AM NOT DONE
>           >          ```
>           >          Пока она не удалена, asmlings не перейдёт к следующему упражнению — даже если код корректен. Это сделано специально, чтобы ты осознанно подтверждал решение.
>           >

>           > ## 4. Краткая теория: 8086 за 5 минут
>           >
>           > ### 4.1 Регистры общего назначения (16 бит)
>           >
>           > | Регистр | Назначение | Половинки |
>           > |---------|------------|-----------|
>           > | `AX` | аккумулятор (арифметика, ввод/вывод) | `AH` / `AL` |
>           > | `BX` | базовый (часто адресация) | `BH` / `BL` |
>           > | `CX` | счётчик (циклы, сдвиги) | `CH` / `CL` |
>           > | `DX` | данные (умножение/деление, порты) | `DH` / `DL` |
>           >
>           > Индексные и указательные: `SI`, `DI`, `BP`, `SP`, `IP`.
>           >
>           > Сегментные: `CS`, `DS`, `ES`, `SS`.
>           >
>           > ### 4.2 Флаги (регистр FLAGS)
>           >
>           > - `ZF` — Zero Flag (результат = 0).
>           > - - `CF` — Carry Flag (перенос).
>           >   - - `SF` — Sign Flag (отрицательный результат).
>           >     - - `OF` — Overflow Flag (переполнение знаковое).
>           >       - - `PF`, `AF`, `DF`, `IF` — реже используются.
>           >        
>           >         - ### 4.3 Память
>           >        
>           >         - Адрес = `сегмент:смещение`. Физический адрес = `сегмент * 16 + смещение`. В ASMLings адресация упрощена — обычно работаешь со смещениями вида `[0x0200]`.
>           >

> ## 5. Синтаксис NASM на пальцах
>
> ```asm
> ; Это комментарий
> section .text          ; секция с кодом
> global _start          ; точка входа
>
> _start:
>     mov ax, 0x1337     ; ax = 0x1337
>     mov bx, ax         ; bx = ax
>     add ax, 1          ; ax = ax + 1
>     hlt                ; остановить процессор
> ```
>
> Несколько правил:
> - Синтаксис **Intel**: `mov dest, src` (приёмник слева, источник справа).
> - - Числа: `42` (dec), `0x2A` (hex), `0b101010` (bin), `'A'` (символ).
>   - - Память в скобках: `mov ax, [0x0200]` — загрузить слово по адресу `0x0200`.
>     - - Метки — `loop_start:`, переходы — `jmp loop_start`.

> ## 6. Базовые инструкции с примерами
>
> ### 6.1 Пересылка `mov`
>
> ```asm
> mov ax, 0x1234        ; немедленное → регистр
> mov bx, ax            ; регистр → регистр
> mov [0x0200], ax      ; регистр → память
> mov cx, [0x0200]      ; память → регистр
> ```
>
> ### 6.2 Арифметика
>
> ```asm
> mov ax, 10
> add ax, 5      ; ax = 15
> sub ax, 3      ; ax = 12
> inc ax         ; ax = 13
> dec ax         ; ax = 12
> neg ax         ; ax = -12 (в дополнении до двух)
> ```
>
> Умножение/деление 8086:
> ```asm
> mov ax, 6
> mov bx, 7
> mul bx         ; DX:AX = AX * BX → AX = 42
> ```
>
> ### 6.3 Сравнение и переходы
>
> `cmp a, b` ставит флаги так же, как `sub a, b`, но результат не сохраняет.
>
> ```asm
> mov ax, 5
> cmp ax, 5
> je  equal       ; jump if equal (ZF=1)
> jne not_equal
> jl  less        ; знаковое <
> jb  below       ; беззнаковое <
> jg  greater
> jmp end
>
> equal:
>     mov bx, 1
> end:
>     hlt
> ```
>
> ### 6.4 Цикл `loop`
>
> ```asm
> mov cx, 5         ; счётчик
> mov ax, 0
> .loop:
>     add ax, 1
>     loop .loop    ; cx--, прыгает пока cx != 0
> ; ax = 5
> ```
>
> ### 6.5 Стек
>
> ```asm
> mov ax, 0xAAAA
> push ax            ; кладём на стек
> mov ax, 0xBBBB
> pop bx             ; bx = 0xAAAA (то, что лежало сверху)
> ```
>
> ### 6.6 Логика и сдвиги
>
> ```asm
> mov ax, 0xF0F0
> and ax, 0x00FF     ; ax = 0x00F0
> or  ax, 0x0F00     ; ax = 0x0FF0
> xor ax, ax         ; ax = 0  ← идиома обнуления
> shl ax, 1          ; сдвиг влево (умножение на 2)
> shr ax, 1          ; сдвиг вправо
> ```
>
> ### 6.7 Строковые инструкции
>
> ```asm
> ; lodsb: AL = [DS:SI], затем SI++
> ; stosb: [ES:DI] = AL,  затем DI++
> mov si, source
> mov di, dest
> mov cx, length
> .copy:
>     lodsb
>     stosb
>     loop .copy
> ```

> ## 7. Разбор типового упражнения
>
> Допустим, asmlings показывает файл `exercises/03_arith.asm`:
>
> ```asm
> ; Задача: получить в AX значение 0x1337
> ; ASSERT_REG: AX == 0x1337
> ; I AM NOT DONE
>
> section .text
> global _start
> _start:
>     mov ax, 0       ; TODO: исправь меня
>     hlt
> ```
>
> **Что делаем:**
>
> 1. Меняем `mov ax, 0` на `mov ax, 0x1337`.
> 2. 2. Удаляем строку `; I AM NOT DONE`.
>    3. 3. Сохраняем файл — asmlings в watch-режиме автоматически пере-собирает и проверяет.
>      
>       4. В терминале появится зелёный `Successfully ran exercises/03_arith.asm!` и asmlings перейдёт к следующему файлу.

>       6. ## 8. Частые ошибки
>
> | Симптом | Причина | Решение |
> |---------|---------|---------|
> | `nasm: command not found` | NASM не установлен | См. раздел 1.2 |
> | Упражнение не зачитывается | Не удалил `; I AM NOT DONE` | Удали строку |
> | `ASSERT_REG: AX == 0x1337 (got 0x0000)` | Не выполнилась нужная инструкция | Проверь, что пишешь в `AX`, а не в `BX`/`AL` |
> | Бесконечный цикл / hang | Забыл `hlt` или неверное условие в `loop` | Добавь `hlt`, перепроверь `cx` |
> | Странные значения после `mul/div` | Результат в `DX:AX`, а не только в `AX` | Учитывай старшее слово в `DX` |
>
> Полезные команды:
>
> ```bash
> asmlings run                # одноразово прогнать текущее упражнение
> asmlings list               # посмотреть статус всех упражнений
> ```

> ## 9. Шпаргалка инструкций 8086
>
