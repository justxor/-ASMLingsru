# 🧪 examples/ — готовые примеры на 8086

Десять самодостаточных `.asm`-файлов с подробными комментариями. Каждый из них:

- **компилируется** через NASM в плоский 16-битный бинарь;
- **запускается** в эмуляторе `asmlings` (можно скопировать содержимое в любое упражнение и убрать `; I AM NOT DONE` — пройдёт ассерты);
- **читается как референс** — даже без запуска.

## Как собрать вручную

```bash
nasm -f bin 01_hello_register.asm -o 01.bin
```

Получится плоский бинарь, который можно загрузить в любой 16-битный эмулятор (qemu в режиме `-machine isapc`, DOSBox через DEBUG.COM, asmlings).

## Как использовать в ASMLings

1. Скопируй содержимое файла.
2. Открой соответствующее упражнение в `exercises/` (например, `exercises/01_bare_metal.asm`).
3. Замени содержимое, удали `; I AM NOT DONE`, сохрани.
4. ASMLings прогонит код через эмулятор и проверит ассерты.

> ⚠️ Это **референсные решения**. Сначала попробуй решить упражнение сам — так гораздо больше пользы.
